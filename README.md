# Catastrophe Risk Simulation

## Objective

Develop a catastrophe risk model for a hypothetical homeowners insurance company.

The model will use SQL, Python, and Excel to analyze catastrophe exposure, simulate future losses using Monte Carlo methods, and calculate actuarial risk measures including Expected Loss, Value-at-Risk (VaR), and Tail Value-at-Risk (TVaR).

## Tools

- Python
- PostgreSQL
- Excel
- Git/GitHub

## Project Timeline

Week 1: Data collection and database development  
Week 2: Risk simulation model  
Week 3: Excel dashboard and actuarial report
